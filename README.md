# Conversor de Moedas

Aplicação web para conversão de moedas estrangeiras para Real (BRL), com cálculo dinâmico e exibição do resultado na interface. Estrutura HTML e CSS fornecidas em curso; lógica de conversão e manipulação do DOM em JavaScript implementadas por mim.

## Tecnologias

- [HTML5](https://developer.mozilla.org/pt-BR/docs/Web/HTML) — estruturação da página
- [CSS3](https://developer.mozilla.org/pt-BR/docs/Web/CSS) — estilização da interface
- [JavaScript](https://developer.mozilla.org/pt-BR/docs/Web/JavaScript) — lógica da aplicação e manipulação do DOM

## Funcionalidades

- Conversão de moedas (USD, EUR, GBP → BRL)
- Atualização dinâmica do valor convertido
- Exibição da cotação utilizada
- Validação de entrada (somente números)
